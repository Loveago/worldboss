# GET /api/orders/:orderId

## Get Order Status

Retrieve the status and details of a specific order.

### Parameters

| Parameter | Type   | Description                        |
| --------- | ------ | ---------------------------------- |
| orderId   | string | The unique identifier of the order |

### Example Request

```bash
curl -X GET https://backend.grandtechub.cloud/api/orders/ord_123456789 \
  -H "X-API-Key: YOUR_API_KEY"
```

### Response

```json
{
  "success": true,
  "data": {
    "id": "ord_123456789",
    "phoneNumber": "233244123456",
    "network": "mtn",
    "dataSize": 100,
    "bundleType": "daily",
    "status": "completed",
    "amount": 10.00,
    "createdAt": "2024-01-15T10:30:00Z",
    "completedAt": "2024-01-15T10:35:00Z",
    "transactionId": "txn_987654321",
    "notes": "Bundle activated successfully"
  }
}
```

### Error Responses

**401 Unauthorized**

```json
{
  "success": false,
  "error": "Invalid API key"
}
```

**400 Bad Request**

```json
{
  "success": false,
  "error": "Invalid request format",
  "details": "phoneNumber is required"
}
```

**429 Too Many Requests**

```json
{
  "success": false,
  "error": "Rate limit exceeded",
  "retryAfter": 60
}
```

### Rate Limits

* Maximum **100 requests per minute** per API key.
* When the limit is exceeded, the API returns **HTTP 429** with a `Retry-After` header.

# GET /api/packages

## Get Packages

Retrieve available data packages by network and type.

> **Note:** The `price` field is returned in **pesewas** (`1 GHS = 100 pesewas`).

### Query Parameters

| Parameter | Type   | Description                                       |
| --------- | ------ | ------------------------------------------------- |
| network   | string | Network provider (`MTN`, `TELECEL`, `AIRTELTIGO`) |
| type      | string | Bundle type (`EXPIRING`, `NON_EXPIRING`)          |

### Example Request

```bash
curl -X GET "https://backend.grandtechub.cloud/api/packages?network=MTN&type=EXPIRING" \
  -H "X-API-Key: YOUR_API_KEY"
```

### Response

{
  "status": true,
  "message": "Packages fetched successfully",

  "payload": [

# POST /api/orders

## Create Orders

Create one or more data bundle orders.

### Request Body

```json
{
  "packages": [
    {
      "packageId": "string",
      "size": 100,
      "network": "MTN",
      "type": "EXPIRING",
      "phone": "233XXXXXXXXX",
      "callback": "https://your-domain.com/webhook/order-status"
    }
  ]
}
```

### Parameters

| Parameter | Type   | Description                       |
| --------- | ------ | --------------------------------- |
| packageId | string | Package identifier                |
| size      | number | Bundle size (GB)                  |
| network   | string | `MTN`, `TELECEL`, or `AIRTELTIGO` |
| type      | string | `EXPIRING` or `NON_EXPIRING`      |
| phone     | string | Recipient phone number            |
| callback  | string | Optional webhook URL              |

### Example Request

```bash
curl -X POST https://backend.grandtechub.cloud/api/orders \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "packages": [
      {
        "packageId": "1",
        "size": 100,
        "network": "MTN",
        "type": "EXPIRING",
        "phone": "233541234567",
        "callback": "https://your-domain.com/webhook/order-status"
      }
    ]
  }'
```

### Response

```json
{
  "status": true,
  "message": "Orders created successfully",
  "statusCode": 200,
  "payload": {
    "orderId": "ord_123456789",
    "totalOrders": 1,
    "totalAmount": 10.00,
    "orders": [
      {
        "id": "sub_001",
        "packageId": "1",
        "phone": "233541234567",
        "network": "MTN",
        "size": 100,
        "type": "EXPIRING",
        "status": "processing",
        "amount": 10.00
      }
    ]
  }
}
```

### Error Responses

**401 Unauthorized**

```json
{
  "success": false,
  "error": "Invalid API key"
}
```

**400 Bad Request**

```json
{
  "success": false,
  "error": "Invalid request format",
  "details": "phoneNumber is required"
}
```

**429 Too Many Requests**

```json
{
  "success": false,
  "error": "Rate limit exceeded",
  "retryAfter": 60
}
```

# Base URL

```
https://backend.grandtechub.cloud
```

All endpoints should now be called using this base URL. For example:

```
https://backend.grandtechub.cloud/api/packages
https://backend.grandtechub.cloud/api/orders
https://backend.grandtechub.cloud/api/orders/{orderId}
https://backend.grandtechub.cloud/api/balance
```
